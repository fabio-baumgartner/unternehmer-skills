# Layout-Katalog

13 Layouts in 5 Kategorien. Eine Infografik = ein Layout. Standardformat 4:5 (1080 x 1350 px). Layouts immer mit Kategorie und Namen zitieren, z. B. "Vergleich: Vorher/Nachher".

## Slot-Vokabular

- `Kicker`: Mikro-Label in Großbuchstaben oben, maximal 3 Wörter. Optional.
- `Headline`: die rahmende Zeile, 6 bis 10 Wörter, ein Wort darf in der Akzentfarbe stehen.
- `Sub`: ein bis zwei Sätze unter der Headline.
- `Stat`: eine einzelne dominante Zahl.
- `Zeile`: eine Dimension in einem Vergleich (Label + Inhalt pro Seite).
- `Chip`: sehr kurze Kennzahl oder Tag ("12 h/Woche", "ab Tag 1").
- `Karte`: Titel (Phrase, kein Satz) + 1 bis 2 Zeilen Text.
- `Kachel`: kleiner Zahlenblock (große Zahl + Mini-Label).
- `Takeaway`: die eine Schlusszeile unten, fett.

Generelle Regel: Fragmente schlagen Sätze. Jede Behauptung trägt eine Zahl oder einen Namen.

## Kategorie 1: Zahl im Fokus

Eine dominante Zahl führt, der Rest der Fläche erklärt sie oder leitet Handlung ab. Der Scroll-Stopper.

### Zahl + Aufschlüsselung
- **Slots:** Kicker, Stat (die große Zahl), Headline, Quellenzeile, Balkendiagramm mit 4 bis 6 Zeilen (Label + Wert), zwei Erklär-Karten ("Warum es zählt" / "Was du tust"), Takeaway.
- **Passt für:** eine Kernstatistik plus eine Rangliste dahinter.

### Zahl + Playbook
- **Slots:** Kicker, Stat, Headline, ein 3-Schritte-Block (nummerierte Mini-Karten mit Pfeilen), zwei Highlight-Karten, 4 Kacheln mit ehrlichen Einschränkungen, Takeaway.
- **Passt für:** eine markante Zahl, die eine kurze Methode einrahmt. Wähle dieses Layout statt der Aufschlüsselung, wenn der Kern eine Vorgehensweise ist, keine Datenrangliste.

## Kategorie 2: Vergleich

Zwei oder drei Optionen nebeneinander über benannte Dimensionen.

### Vorher/Nachher
- **Slots:** Headline (ein rot markiertes Vorher-Wort, ein grün markiertes Nachher-Wort), Sub, zwei Spaltenköpfe mit VS-Knoten, 5 Zeilen (Label + rote Zelle mit Chip + grüne Zelle mit Chip), unten 4 Ergebnis-Kacheln.
- **Passt für:** Alt gegen Neu, wenn jede Seite pro Dimension eine messbare Zahl hat.

### VS mit Fazit
- **Slots:** wie Vorher/Nachher, aber statt Kacheln eine dunkle Fazit-Box mit einem klaren Urteilssatz.
- **Passt für:** denselben Zwei-Wege-Kontrast, wenn die Dimensionen qualitativ sind (Aufwand, Logik, Verlässlichkeit) und die Pointe ein Satz ist.

### Dreifach-Teardown
- **Slots:** drei Namens-Pills, drei Score-Karten (Name + Punktzahl), Bewertungszeilen pro Gruppe (Haken/Kreuz + Kurztext), Pro/Contra-Karten, drei Urteils-Karten ("Nimm X, wenn ...").
- **Passt für:** einen tiefen Drei-Optionen-Vergleich (Tools, Tarife, Ansätze). Das dichteste Layout, nur mit genug Substanz wählen.

## Kategorie 3: Schritte und Raster

Nummerierte oder parallele Karten: Prozesse, Tipps, Frameworks, Abläufe.

### Prozess-Raster
- **Slots:** Headline, Sub, 2x3-Raster nummerierter Schritt-Karten (Nummernkreis + Titel mit 2 bis 4 Wörtern + 1 bis 2 Zeilen + optional ein kleines Stützelement wie Chip-Reihe oder Beispielbox). 4 bis 6 Karten.
- **Passt für:** eine Anleitung in geordneten Schritten (erst 1, dann 2).

### Tipp-Karten
- **Slots:** Headline, Sub, 2x3-Raster getönter Karten (Nummer + Titel + eine Zeile + Beispielbox). 4 bis 6 Karten.
- **Passt für:** parallele Tipps von gleichem Gewicht, Reihenfolge egal.

### Akronym-Framework
- **Slots:** Headline, Sub, ein Block mit 3 bis 5 Buchstaben-Zeilen (großer Buchstabe + Name + Kurztext), ein Vorher/Nachher-Paar (Kreuz-Liste und Haken-Liste), 3 nummerierte Regeln.
- **Passt für:** ein benanntes Framework mit einprägsamem Akronym.

### Ablauf-Showcase
- **Slots:** Headline, Sub, 2 bis 4 große Karten, jede mit Nummer + Titel + Auslöser-Badge ("täglich", "bei Ereignis") + 3-Knoten-Kette (Werkzeug + Aktion, Pfeile dazwischen) + Ergebnis-Zeile. Unten ein Hinweis-Streifen.
- **Passt für:** konkrete Abläufe oder Automatisierungen als Werkzeug-zu-Werkzeug-Ketten.

## Kategorie 4: Listen und Checklisten

### Verzeichnis
- **Slots:** Kopfzeile, Headline, Sub, 2-spaltiges Raster aus 4 bis 6 Kategorie-Gruppen (farbiges Label + 2 bis 4 Einträge mit Name und Kurzbeschreibung).
- **Passt für:** eine gruppierte Sammlung (Werkzeugkasten, Ressourcenliste, Leistungsübersicht). Textdicht, ohne große Visuals.

### Icon-Stapel
- **Slots:** Titelband oben, senkrechter Stapel aus 4 bis 6 Zeilen (Icon-Chip + Beschreibungskarte mit 1 bis 2 Zeilen), fette Schlusszeile.
- **Passt für:** eine flache Liste, jedes Element ein Tool oder eine Person mit einem kurzen Urteil. Sehr gut scanbar.

### Do / Don't
- **Slots:** Headline, Sub, grüne "Mach das"-Karte (bis 5 Einträge mit Icon + Titel + Zeile), rote "Mach das nicht"-Karte (bis 5 Einträge), Takeaway-Banner.
- **Passt für:** Ratschläge, die sauber in richtig und falsch zerfallen.

## Kategorie 5: Konzept und Modell

### Gleichungs-Modell
- **Slots:** große Aussage in einer Zitatbox + Sub, eine Gleichungszeile aus 2 bis 3 Karten ("Du" + "System" = "Ergebnis", Ergebnis-Karte dunkel), eine kleine Beweiszeile (Mini-Diagramm oder 3 Kacheln), ein Block mit 3 Reflexionsfragen, Takeaway.
- **Passt für:** ein Denkmodell oder eine "X + Y = Z"-Idee. Eine große Idee, keine Liste.

## Entscheidungshilfe: Form → Layout

| Form des Inhalts | Layout |
|---|---|
| Eine Zahl dominiert, dahinter eine Rangliste | Zahl + Aufschlüsselung |
| Eine Zahl dominiert, dahinter eine Methode | Zahl + Playbook |
| Alt gegen Neu, messbare Zahlen pro Seite | Vorher/Nachher |
| Alt gegen Neu, qualitativ, Pointe als Satz | VS mit Fazit |
| Drei Optionen im Detail | Dreifach-Teardown |
| Geordnete Schritte | Prozess-Raster |
| Parallele Tipps | Tipp-Karten |
| Benanntes Framework mit Akronym | Akronym-Framework |
| Werkzeug-Ketten mit Ergebnis | Ablauf-Showcase |
| Gruppierte Sammlung | Verzeichnis |
| Flache Liste mit Urteilen | Icon-Stapel |
| Richtig vs. falsch | Do / Don't |
| Ein Denkmodell | Gleichungs-Modell |

| Layout | Fix / flexibel | Idealer Umfang |

| Zahl + Aufschlüsselung | flexibel | 1 Zahl + 4 bis 6 Balken + 2 Karten |

| Vorher/Nachher | fix 5 Zeilen | 2 Seiten, Zahl pro Seite |
| VS mit Fazit | fix 5 Zeilen | 2 Seiten, qualitativ + Fazit |
| Dreifach-Teardown | fix 3 | tiefer 3er-Vergleich |
| Prozess-Raster | 4 bis 6 | geordnete Schritte |
| Tipp-Karten | 4 bis 6 | parallele Tipps |
| Akronym-Framework | 3 bis 5 Buchstaben | benanntes Framework |
| Ablauf-Showcase | 2 bis 4 | konkrete Abläufe |
| Verzeichnis | 4 bis 6 Gruppen | gruppierte Sammlung |
| Icon-Stapel | 4 bis 6 | flache Liste |
